## Conventions

- **One file per item,** named `<id>-<short-title>.md` in lowercase with hyphens (for example `fr-001-telegram-bot-interface.md`).
- **Stable IDs:** `FR-001`, `NFR-001`, `CON-001`. Never reused or renumbered.
- **Priority (MoSCoW):** Must, Should, Could, Won't.
- **Status:** Proposed, Accepted, Implemented, Dropped.
- Every requirement must be verifiable.
