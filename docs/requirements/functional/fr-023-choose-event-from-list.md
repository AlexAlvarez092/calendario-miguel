# FR-023: Choose the event from a list

- **Priority:** Must
- **Status:** Dropped

When Miguel uses the command to modify or remove an event ([FR-006](fr-006-remove-event-command.md), [FR-007](fr-007-modify-event-command.md)), the bot shows a list of events and Miguel chooses the one to change.

Dropped because Miguel identifies the event by indicating the day (see [FR-007](fr-007-modify-event-command.md)).
