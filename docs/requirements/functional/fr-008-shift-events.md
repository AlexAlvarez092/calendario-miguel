# FR-008: Shift events

- **Priority:** Must
- **Status:** Proposed

Each work shift is a calendar event with a date, a start time and an end time.

## Acceptance criteria

- Given a shift of Miguel on a day, When its event is created, Then the event shows that day's date, the start time and the end time of the shift in the Europe/Madrid time zone ([FR-021](fr-021-time-zone.md)).
