# CON-001: Run on the Raspberry Pi

- **Status:** Accepted

The Telegram bot must run on the Raspberry Pi `pi3`.

## Hardware and system

| Item | Value |
|------|-------|
| Model | Raspberry Pi 3 Model B+ Rev 1.3 |
| Memory | 1 GB RAM (about 900 MB visible to the system), no swap |
| CPU | Cortex-A53, 4 cores, up to 1.4 GHz, aarch64 (64-bit) |
| Operating system | Ubuntu 24.04.5 LTS (kernel 6.8.0-1068-raspi) |
