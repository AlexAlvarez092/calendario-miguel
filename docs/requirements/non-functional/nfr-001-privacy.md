# NFR-001: Privacy

- **Category:** Privacy
- **Priority:** Must
- **Status:** Proposed

No access restriction on the calendar is required for now (see [FR-011](../functional/fr-011-subscription-url.md)). Restricting access is a possible future improvement.

## Acceptance criteria

- Given the calendar is published, When anyone requests it, Then no additional access restriction is applied beyond what is described in the acceptance criteria of [FR-011](../functional/fr-011-subscription-url.md).
