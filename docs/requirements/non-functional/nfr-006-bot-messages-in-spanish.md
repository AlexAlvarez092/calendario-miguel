# NFR-006: Bot messages in Spanish

- **Category:** Usability
- **Priority:** Must
- **Status:** Proposed

All messages the bot sends to Miguel are in Spanish. This is the exception allowed by the [language rule](../../../.github/instructions/language.instructions.md); the code, comments and documentation stay in English.

## Acceptance criteria

- Given any interaction with the bot, When the bot replies to Miguel, Then the message is written in Spanish.
