# NFR-006: User-facing text in Spanish

- **Category:** Usability
- **Priority:** Must
- **Status:** Accepted

All text that Miguel and his friends see is in Spanish: the messages the bot sends to Miguel and the titles of the calendar events. This is the exception allowed by the [language rule](../../../.github/instructions/language.instructions.md); the code, comments and documentation stay in English.

## Acceptance criteria

- Given any interaction with the bot, When the bot replies to Miguel, Then the message is written in Spanish.
- Given any event of the calendar, When it is shown in a calendar app, Then its title is written in Spanish.
